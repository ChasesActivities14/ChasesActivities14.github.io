Privacy Policy

Jarvis · Effective November 17, 2026

Jarvis is a private, personal-use AI assistant app built and run by Chase Zaidan for his own use. It is not a commercial service and is not available to the public. This policy explains, in plain English, what data Jarvis accesses and how it is handled.

What data Jarvis accesses

With the account owner's permission, given through Google's sign-in and consent screen (Google OAuth), Jarvis can read the owner's Gmail messages and settings. It uses only the read-only scope https://www.googleapis.com/auth/gmail.readonly. Jarvis cannot send, delete, change, or label email, and it cannot change any Gmail settings.

Why Jarvis uses it

Only to summarize and organize the owner's own email for that owner, for example short summaries of new messages or grouping messages that need attention. The data is not used for any other purpose.

Where it is processed and stored

  • Jarvis runs on a private server controlled by the account owner. The Google sign-in tokens and any summaries Jarvis creates are kept there, with access limited to the owner.
  • Jarvis's workspace, where summaries or notes may be saved, is also synced to the owner's private backups: a private GitHub repository that only the owner can access, and the owner's own computer. GitHub stores this backup only as a hosting provider.
  • To generate summaries, the content of the relevant email messages is sent to Anthropic's Claude API over an encrypted (HTTPS) connection, and the result is returned to Jarvis. Anthropic processes this data under its own commercial terms and privacy policy. By default, Anthropic does not use inputs or outputs from its API to train its models (source).
  • Email content and summaries are never sent to any text-to-speech or other voice service.
  • All of these transfers use encrypted connections.

Sharing

  • Gmail data is not sold, rented, or traded to anyone.
  • It is not shared with any third party, except sending email content to Anthropic's Claude API to generate the summaries described above.
  • It is never used for advertising, including targeted, personalized, or interest-based ads.
  • It is not used to develop, improve, or train generalized artificial intelligence or machine-learning models.
  • No other person reads the data. Only the account owner sees their own email and summaries.

Retention and deletion

Jarvis keeps only what it needs to summarize and organize the owner's email, for no longer than needed for that purpose. The owner can ask for any stored data to be deleted at any time by writing to the email address below.

Access can be revoked at any time at myaccount.google.com/permissions. Once revoked, Jarvis can no longer read any Gmail data.

Google API Services User Data Policy

Jarvis's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

If this policy changes, the updated version will be posted on this page with a new effective date.
